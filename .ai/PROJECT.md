# Project

## Name

portefolio

## Purpose

Portfolio conçu pour illustrer les compétences en Flutter et offrir un aperçu clair du parcours d'Emryck Doré.

## Target

Recruteurs, clients potentiels, communauté Flutter.

## Platforms

- [x] Android
- [x] Web
- [x] iOS
- [x] Linux
- [x] Windows
- [x] MacOS

## Flutter

Version utilisée :

```
>=3.10.0
```

## Dart

Version utilisée :

```
>=3.0.0 <4.0.0
```

## Architecture

Architecture modulaire orientée "Feature-First" avec Riverpod pour la gestion d'état.

## State management

Riverpod (flutter_riverpod ^3.0.3)

## Backend

Supabase (supabase_flutter ^2.10.4)

## Authentication

Google Sign In (pour la partie admin)

## Important constraints

- Multiplateforme (Responsive design critique)
- Performance des animations (Rive, Lottie, flutter_animate)
- SEO pour la partie Web
