# GODZYKEN Flutter AI Template Integration

Ce projet est équipé d'un "cerveau de développement" IA cohérent via le template **GODZYKEN Flutter AI**.

## Structure IA

- **AGENTS.md** : Règles permanentes pour l'agent IA.
- **.ai/** : Documentation vivante du projet (Project, Architecture, Roadmap, Decisions, Tasks).
- **.agents/** : Skills Flutter/Dart pour l'agent.
- **.mcp/** : Configuration du serveur MCP Dart/Flutter pour les diagnostics et l'inspection.

## Dépendances Clés

- **State Management** : Riverpod ^3.0.3
- **Animations** : Rive, Lottie, Flutter Animate
- **Charts** : fl_chart ^1.1.1
- **Backend** : Supabase

## CI/CD

Les workflows GitHub Actions gèrent :
- Analyse statique et tests unitaires.
- Build Android (APK) et Web.
- Releases automatiques sur tag `v*`.
